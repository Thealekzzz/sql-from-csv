## sql-from-csv

Программа трансформирует XLSX файлы, экспортированные из AltaGenetics в sql файлы для БД
При этом она автоматически проверяет дублирование по заданным столбцам и разделяет большие файлы на чанки по 50000 записей

Как пользоваться:

## Запуск программы

1. Закинуть все XLSX файлы в папку ./input
2. В программе задать корректное название таблицы БД
3. Запустить программу

## Проверка

4. Полученные файлы импортировать в MySQL Open Server
5. Проверить получение данных SQL запросом

## Обновление базы

6. Отправить файлы на сервер командой `scp -r ./result/* root@81.200.152.150:/root/sqls/<название таблицы БД>/`
7. Зайти на сервер, перейти в папку /root/sqls/ `cd /root/sqls/<название таблицы БД>/`
8. Зайти в mysql `mysql -u root -p` и запустить команду source для каждого файла в папке `source <file>`
