## sql-from-csv

Программа трансформирует CSV файл, сохраненный в UTF-8 с ";" в качестве разделителя в SQL файл.
При этом она автоматически проверяет дублирование по заданным столбцам и разделяет итоговый файл на чанки по 50000 записей

Как пользоваться:

## Подготовка данных
1. Объединить таблицы с данными
   1. Закинуть все таблицы в папку ./join/input
   2. Запустить объединение
2. Поместить .csv или .txt файл в папку input

## Запуск программы
6. В программе задать корректные filename, resultFilename и tableName
7. Запустить программу

## Проверка
8. Полученные файлы импортировать в MySQL Open Server
9. Проверить получение данных SQL запросом

## Обновление базы
10. Отправить файлы на сервер командой `scp <source> root@81.200.152.150:/root/sqls/`
11. Зайти на сервер, перейти в папку /root/sqls/ `cd /root/sqls/`
12. Зайти в mysql `mysql -u root -p` и запустить команду source для каждого файла в папке `source <file>`
